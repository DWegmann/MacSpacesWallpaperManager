# Mac Spaces Wallpaper Manager 1.3.1

- Translated the app interface into English, including menus, settings, folder dialogs, tooltips and accessibility labels.
- Translated app error messages, status notices, color names and command-line diagnostics into English.
- Set English as the app's default language and updated the English and German documentation to match the interface.

Requires macOS 13 or later. The universal app supports Apple Silicon and Intel Macs.

Existing settings and Space assignments are preserved. Version 1.3.0 can install this release through **Check for Updates…**. Older versions require a manual installation.
